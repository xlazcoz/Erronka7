APIa abiarazteko, `api_erronka` karpetan:
uv run python -m uvicorn main:app --host 0.0.0.0 --port 8000

Demo datuak kargatzeko, behin bakarrik eta `api_erronka` karpetan:
uv run python seed.py

Frontend-a VS Code Live Server erabiliz ireki `index.html` (Hasiera) fitxategitik
(http://localhost:5500 edo http://127.0.0.1:5500). Estazioak `Kargaguneak.html`
orrian daude. APIak PostgreSQL zerbitzaria `localhost:5432` portuan martxan egotea
behar du.

QR / taquilla:
- Erabiltzaileak "Mis reservas" atalean QR-a deskargatu edo inprimatu dezake.
- Adminak `locker.html` ireki behar du (admin saioa hasita), estazioa konfiguratu
  eta QR-a irakurri. QR-a ez du estazioak sortzen: erabiltzaileak eramaten du.
- QR-a URL bat da: `locker.html?token=...`. Gailu beretik edo kameraren bidez
  ireki daiteke.
- Tokian bertan HTTP bidezko kamerak ez du funtzionatzen; erabili kameraren
  aplikazioa edo sartu kodea eskuz. HTTPS-rekin kamerak barruan funtzionatzen du.

Testak exekutatzeko, `api_erronka` karpetan:
uv run python -m unittest discover -s tests -p "test_*.py"
