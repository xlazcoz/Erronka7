APIa abiarazteko, `api_erronka` karpetan:
uv run python -m fastapi dev main.py

Demo datuak kargatzeko, behin bakarrik eta `api_erronka` karpetan:
uv run python seed.py

Frontend-a VS Code Live Server erabiliz ireki `index.html` fitxategitik
(http://localhost:5500 edo http://127.0.0.1:5500). APIak PostgreSQL zerbitzaria
`localhost:5432` portuan martxan egotea behar du.

Erreserben arauak:
- Powerbankak gaurko egunean bakarrik erreserbatu daitezke.
- Gehienez 6 ordu aurretik egin daiteke erreserba.
- Erreserbak gutxienez 15 minutu eta gehienez 6 ordu iraun dezake.
- Karga-postu berean ezin dira ordutegi gainjarriko erreserbak egin.
- Etorkizuneko erreserba batek ez du gaurko erabilgarritasuna blokeatzen.
