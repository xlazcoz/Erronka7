# Hirugarrenen baliabideak eta lizentziak

Dokumentu hau **Powerbank Alokairu Sistema** proiektuan erabilitako hirugarrenen materialen erregistroa da. Lizentziak **2026ko azaroaren 4an** egiaztatu ziren.

Proiektuaren kode eta dokumentazioaren lizentzia: **PolyForm Noncommercial License 1.0.0** (`LICENSE`). Erabilera komertzialak lizentzia komertzial ordaindua behar du: `hola@powerbank.eus`.
